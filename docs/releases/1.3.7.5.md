# Mac Xcloud 1.3.7.5

## Maintenance release
- Simplified the adaptive-trigger pipeline: preset management and trigger commands are slimmer and focus on the DualSenseX-style effect list introduced in 1.3.7.
- Trimmed the controller model and feature service code paths; native input, rumble, gyro steering and profile recall behaviour are unchanged.
- Settings panel improvements: the Clarity pane now reports live pipeline status, writes are verified against Better xCloud readbacks before the UI commits, and Unlimited bitrate is preserved across panel reloads.
- Removed the bundled FSR upscaler engine (upscaler-core.js). Clarity sharpening and scaling now rely on Better xCloud's built-in renderer options; the FSR 1 entry in the pipeline picker will not attach until the engine ships again.
- Rewrote the README to match the current feature set.

## Compatibility
- Universal (Apple Silicon + Intel) build checks unchanged; this release was verified to compile in Debug for the current scheme.

## Notes
- No controller firmware or stream format changes. Saved profiles and settings carry over from 1.3.7.
