# Mac Xcloud 1.3.8

## New features
- New opening animation, centered on a black background. The page loads in the background while the video plays.
- Added deep links so games can be launched from Raycast, the terminal, or browser links: macxcloud://play/<game-id> starts a game, macxcloud://resume reopens the last game, macxcloud://home goes to the start page. The current game's ID is shown in the Diagnostics panel with a copy button.
- When a queued game is ready, you get a Mac notification and the controller lightbar pulses green three times with a rumble, so you can do something else while waiting.
- The Mac no longer goes to sleep while the app is running.
- Added a quit confirmation when a game is still streaming.
- Settings search in the settings window header.
- Export or import all settings and profiles as one file (Settings > Backup & Restore).
- Window size and position are now remembered per display.
- Low controller battery now sends a Mac notification, and the low-battery lightbar behavior also works while streaming.

## Fixes
- Steering no longer drifts while the controller vibrates from game rumble or adaptive-trigger effects (new "Ignore rumble shake" setting, on by default).
- Fixed the Loading badge sometimes staying on screen after the page finished reloading.
- Offline handling: the app now detects a dropped connection, shows a clear message, and reloads automatically when it returns.
- Fixed the splash video sometimes freezing on its last frame on slow connections.
- Minor UI fixes and general reliability improvements.

## Compatibility
- macOS 12+ universal build (Apple Silicon + Intel). Saved profiles and settings carry over from 1.3.7.x.
