# Mac Xcloud 1.4.0

## New
- Keyboard and mouse play as an Xbox controller in games made for controllers. Keys work as soon as the game starts, a click captures the mouse for the camera, tap Esc to pause, hold Esc to release the mouse.
- Your own keyboard layouts: start from Standard or Shooter, click a key cap and press the new key, mouse button or scroll direction.
- Gyro pause button: hold or tap a chosen button (the touchpad works well) to reposition your hands without moving the camera.
- Gyro can aim with the mouse in games that support keyboard and mouse: one to one, no stick dead zone.
- Connection health in Settings › Performance: what is wrong (weak Wi‑Fi, 2.4 GHz, packet loss, latency spikes, slow decoding) and what to do, with a short notice in the game when a problem lasts.
- Setup suggestion for new racing games and shooters, saved for that game only. Not Now dismisses it, and it can be turned off.
- Recent games in Spotlight, the Dock menu and the menu bar. Shortcuts and Siri can start a game or resume the last one.
- Optional: feel the game's sound as vibration (engines, impacts, explosions), per game.
- Optional: play games in full screen, so macOS can use Game Mode. The Motion page shows how often the controller sends motion data.

## Improved
- Gyro drift: the offset is measured exactly whenever the controller rests on a table and kept between launches. Holding the controller no longer teaches it slow deliberate turns as drift.

## Fixes
- Keys did nothing in games without keyboard and mouse support (Forza Horizon 6). The virtual controller now presses buttons the same way a real controller does.
- A blank black window could stay open behind the game window.
