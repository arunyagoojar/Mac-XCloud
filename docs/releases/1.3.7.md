# Mac Xcloud 1.3.7

## Steering and controller feedback
- Improved steering-wheel motion tracking: gyro prediction follows quick turns while absolute sensor correction reduces accelerometer jolts and keeps held turns steady.
- Preserved gyro aiming, touchpad aiming and bidirectional flick shifting. For flick shifting, enable manual gears and map right-stick up to upshift and right-stick down to downshift inside the game.
- Replaced the default adaptive-trigger menu with the DualSenseX-style list: Normal Trigger, Custom Trigger Value, GameCube, Resistance, Bow, Galloping, Semi Automatic Gun, Automatic Gun, Machine, Choppy, Very Soft through Hardest, Rigid, Calibrate and the Vibrate presets. Each name maps to the controller's documented effect primitives; the previous twelve designs stay loadable for saved selections.
- Added pressure-driven haptic rhythms, pistol/bow release feedback and bounded recoil resistance. Existing saved and custom effects remain loadable.

## Settings and navigation
- Removed the persistent on-screen Back and Home buttons.
- Added Backspace for browsing back, with protection for typing, text editing and gameplay. Existing Mac navigation shortcuts remain available.
- Listed app shortcuts in Settings → App → About.
- The menu bar status icon is removed as soon as the app quits.
- Fixed immediate OLED background updates and made global settings show when a reload is needed.
- Removed remaining keyboard/mouse gaming settings. WKWebView limitations made reliable gaming support impractical; ordinary typing, clicking and app shortcuts remain available.

## Profiles and usability
- Per-game profile recall restores controller, motion, trigger and selected picture/audio settings, using game IDs with website-title fallback.
- Native settings use five main groups, with advanced steering controls and diagnostics collapsed.
- Rewrote the README with the current feature list, controller requirements, limitations and a Forza Horizon 5 cruising setup.

## Compatibility and remote play
- Verified Intel and Apple Silicon compilation and added a release check requiring both executable architectures.
- Fixed console-list readiness and refreshes stale console status when reopening Remote Play.
- Xbox waking from standby remains unresolved; streaming from an already powered-on console is supported.

## Notes
- Trigger effects are local simulations, not weapon telemetry from Xbox games. Hardware resistance zones and scheduled haptics approximate the requested effects.
- Steering feel depends on your controller, connection, car and in-game settings. The user has confirmed the revised steering is usable; further tuning is personal.
- Automatic-update dialogs now display these release notes instead of a commit hash.
